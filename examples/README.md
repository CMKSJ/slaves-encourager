# Synthetic examples / 虚构样本

Every example uses fictitious quantities/costs and contains no real account information. Stock prices/costs here are not market quotes.

- `holdings-sample.csv`: UTF-8 CSV with symbol, quantity, per-share cost and currency.
- `holdings-sample.xlsx`: first-sheet values-only workbook.
- `holdings-sample.png`: clear screenshot for local OCR, visibly marked synthetic.
- `holdings-table.html`: visible HTML table for paste/extension extraction, including a fake Account column that the extension must omit.

Start with these before trying a manually reviewed broker export. See [the detailed beta guide](../docs/STOCK_BETA.md).
