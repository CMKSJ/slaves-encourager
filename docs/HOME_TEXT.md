# 主页文字 / Home text

双击主页的固定文字，直接打开对应文案。右键按钮或主页空白处，选择「编辑主页文字」，也可按 `Ctrl+E`。下拉列表包含标题、说明、金额标签、各工作状态、倒计时标签、目标提示、按钮文字和悬浮提示，包括当前没有显示的状态。

修改后点「保存并应用」，主页立即更新，下次启动继续使用。取消会放弃整个编辑会话。可恢复单项或当前语言的全部文案；其他语言的修改不受影响。每种语言独立保存，切换语言后使用该语言的默认文案或自定义文案。

每项最多 300 字。允许清空没有数字占位符的文案以隐藏它。带实时数据的文案必须原样保留默认占位符，例如 `{0:F2}`、`{1:F2}`，可以调整它们的位置。错误会显示在编辑器中，保存和切换项目均不会丢失待修正的输入。恢复操作在点击保存前均可取消。

工资、时间、目标名称和金额继续在原来的设置页修改。文字编辑保存为本机设置中的 `HomeText`，键由语言和文案编号组成；不改变排班、收入计算、按钮动作或快捷键。它不修改翻译目录。旧设置没有这个字段时继续显示默认翻译。

Double-click fixed home text to edit that caption. Right-click a button or the home background and choose **Edit home text**, or press `Ctrl+E`. The list includes headings, descriptions, amount labels, all work states, countdown labels, goal hints, button captions and tooltips, including states currently hidden.

**Save & apply** updates the home screen and persists edits across restarts. Cancel discards the editing session. Reset one caption or every caption in the current language; other languages stay intact. Each language has independent overrides.

Each entry allows up to 300 characters. Plain captions may be empty. Preserve numeric placeholders exactly, including formatting such as `{0:F2}`; their order may change. Invalid input stays available for correction. Salary, schedules, goal names and amounts use their existing settings controls. Copy changes do not alter calculations, button behavior or shortcuts.
