# Icon / 图标说明

The current icon combines a friendly ox head with a small clock. It uses misty blue, warm ivory and apricot. There are no letters or words in the artwork.

图标使用内置 `image_gen` 生成，并按用户要求把初版深绿色改成雾蓝、米白和暖杏。没有使用原项目图标或第三方素材。

- Source: `assets/app.png`, PNG/RGBA, 1254 × 1254 pixels, with transparent exterior (alpha 0–255).
- Windows output: `assets/app.ico`, seven sizes: 16, 24, 32, 48, 64, 128 and 256 pixels.
- App header, window/taskbar icon and tray use the same asset.
- `scripts/create-icon.ps1` performs size/format conversion only; it does not redraw the artwork.

## Final edit prompt

Keep the happy ox head, upward horns, clock hands, balanced composition, rounded-square shape and transparent exterior. Change only the palette to dusty periwinkle blue (approximately `#617DB5`), warm ivory (`#FFF3DC`) and muted apricot (`#E7AF85`). Eyes, smile and nostrils use the blue background color. No green, text, letters, added objects or mockup presentation. Preserve transparency outside the tile.

The PNG is included in the MIT project as generated artwork; no exclusive-rights claim is made. Dimensions, format and ICO frame sizes are checked during release preparation.
