## 简体中文

- 双击主页文字、右键按钮或按 `Ctrl+E` 编辑固定文案；按语言保存，支持取消、恢复默认和数字占位符保护。
- 翻页时钟收入、滑动或静态数字；支持小数位、千分位、币种符号和自定义格式。
- 可点击的休息/补班日历、跨午夜排班、下班倒计时和最多 20 个有序目标。
- 六语言界面、雾蓝暖杏图标和三种主题；隐私模式、迷你模式、置顶、托盘及非按钮区域拖动。
- 本地运行，无遥测，MIT 开源；六份 README 均提供居中徽章、语言切换与下载入口。

下载 **SlavesEncourager-1.3.1-windows-portable.zip**，解压后运行 `SlavesEncourager.exe`。需要 Windows 10/11 和 .NET Framework 4.8。旧设置继续兼容。

收入和目标按排班估算，过去排班默认满勤，不代表实际到账或储蓄；币种仅改变符号。
