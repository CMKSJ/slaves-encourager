# Slaves Encourager 1.3.1

## 中文

- 双击主页文字或右键按钮直接编辑，支持分语言保存、恢复默认与实时数字占位符保护。

- 全新牛角＋时钟图标，配色调整为雾蓝、米白和暖杏。
- 移除旧的品牌后缀，统一为「牛马鼓励器 / Slaves Encourager」。
- 完整支持简体中文、繁体中文、英语、日语、西班牙语和韩语，支持系统默认、预览和保存选择。
- 保留翻页收入、格式自定义、工作日历、多目标、隐私模式、迷你模式、托盘及非按钮区域拖动。
- 整理独立源码目录、六语言 README、开发/贡献/发布说明、自动构建配置与 MIT 许可证。

使用：退出旧版，解压便携包，运行 `SlavesEncourager.exe`。需 Windows 10/11 和 .NET Framework 4.8。旧设置继续读取，用户输入的目标和格式不会自动翻译。

收入和目标为排班估算，不代表实际到账或储蓄。全国节假日请按自己的排班手动指定。当前验证范围见随包记录，远程 CI 结果见仓库 Actions。

## English

- Clean Slaves Encourager branding.
